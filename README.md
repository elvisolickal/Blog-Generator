# AI Blog Generator

An AI-powered blog generation web application built using Streamlit and Google Gemini AI.

## Features
- Generate blogs instantly
- Choose word count
- Select target audience
- Clean UI using Streamlit

## Technologies Used
- Python
- Streamlit
- Google Gemini API

## Run the Project

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the app:

```bash
streamlit run app.py
```
